# Todo List App

A simple, elegant web-based todo list application built with vanilla HTML, CSS, and JavaScript.

## Features

✅ **Add Tasks** - Quickly add new tasks to your list
✅ **Mark Complete** - Check off tasks as you complete them
✅ **Delete Tasks** - Remove tasks you no longer need
✅ **Persistent Storage** - Your todos are saved to local storage and persist across browser sessions
✅ **Task Statistics** - See your total tasks and completed count at a glance
✅ **Responsive Design** - Works great on all screen sizes

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field and click "Add" or press Enter
3. Check the checkbox to mark a task as complete
4. Click "Delete" to remove a task
5. Your tasks are automatically saved!

## Files

- **index.html** - The main HTML structure
- **styles.css** - Beautiful styling with gradient background
